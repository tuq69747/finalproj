# Final Visualization Project - Indego Bike Sharing 

This project focuses on the usage of Indego bike sharing, the ratios between electric and standard bikes, the various passholder types, and possible new stations. Our website can be found at https://tuq69747.github.io/finalproj/.

In this project we learned: 
- mouseover effects in D3
- adding points to leaflet using data from geojson files
- creating pie charts using D3
- adding zoom effects in HTML and D3
- CSS containers 
- hosting on GitHub pages
